# Ludovic Fioklou — Portfolio

A single-page portfolio for small Java, Spring Boot, Angular, SQL, and API integration assignments. The site is static and has no build dependencies.

## GitHub Pages

1. Create a GitHub repository and push this project to its `main` branch.
2. In **Settings → Pages**, set **Build and deployment → Source** to **GitHub Actions**.
3. The workflow in `.github/workflows/pages.yml` publishes the contents of `dist/` on each push to `main`.

The published URL is `https://<username>.github.io/<repository>/` for a project repository, or `https://<username>.github.io/` for a repository named `<username>.github.io`.

## Editing

Edit `dist/index.html`. The Upwork buttons point to Ludovic's public profile. Keep any employer-owned source code, screenshots, and operational data out of the public repository.
